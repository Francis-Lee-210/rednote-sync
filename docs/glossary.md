# 术语表

状态：**当前权威**

| 术语 | 含义 | 不等同于 |
|---|---|---|
| 产品阶段 | 当前产品的列表导出、内容下载、本地整理与后续操作三个功能阶段 | 历史实施 Stage 1–4 |
| 历史实施阶段 | 插件逆向、协议提炼、离线 Core、在线采集预留的旧研发顺序 | 当前产品路线图 |
| 在线采集 | 用户主动运行产品功能，从平台读取自己的列表、详情或媒体 | 为发现未知行为而进行的研究实验 |
| 在线探测 | 历史研究中用于验证接口、页面行为、限制信号或环境差异的受控实验 | 所有正常在线采集 |
| 当前权威 | 已由用户确认、用于描述现行产品目的、功能或优先级的文档 | 研究建议或 Agent 推断 |
| 已实现契约 | 当前代码已经遵守的接口、状态或数据约束 | 未来产品必须永久保持的设计 |
| 概念草案 | 为未来讨论建立共同语言，但不规定实现细节 | 可编码的协议规范 |
| 探索 | 未被采纳的候选架构、模型或工作流 | 当前架构承诺 |
| 研究证据 | 固定来源、版本和范围下得到的事实与判断 | 产品决定或安全保证 |
