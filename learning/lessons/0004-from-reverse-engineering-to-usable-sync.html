为什么测试很多，仍然不能同步真实账号

测试使用的是完全合成的数据。它能证明“给定一页合法输入，系统会正确保存、恢复和导出”，却不能证明“小红书今天仍返回同样的字段、游标和排序”，也不能证明登录、Cookie 和页面签名在真实浏览器里能稳定工作。

当前：合成 JSON → 离线同步核心 → SQLite / Markdown / JSON / media
缺口：真实账号 → 浏览器登录与签名 → 当前网站响应 → 上述离线核心
类比：发动机已经在测试台上通过耐久试验，但车辆还没有安装油路和方向盘。测试台成功是真成果；它也不等于现在能开上公路。
