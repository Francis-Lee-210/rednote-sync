第一版标签是种子，不是围墙

状态：学习材料。 本页用于解释历史研究或候选方案，不是当前产品设计；现行状态见产品路线图。

新增帖子当然可能超出旧类别。正确做法不是频繁推倒重来，也不是把新内容硬塞进最接近的旧标签，而是让系统明确承认“未知”。

封闭分类与开放分类

方式遇到全新内容时后果
封闭分类必须从现有标签里选一个看似整齐，但会持续制造错误分类
开放分类允许输出“未知/需要新标签”保留不确定性，之后可增量扩展词表

这类问题在机器学习中通常称为开放世界识别：系统既要识别已知类别，也要拒绝未知类别，并在获得新标签后逐步扩展。可参阅基础论文 Towards Open World Recognition。

一次新增同步应如何运行

  1. 新帖子先与现有标签定义和代表性样本比较。
  2. 匹配明确时，直接使用已有标签。
  3. 匹配不明确时，不强行归类；写入 needs_taxonomy_review。
  4. 系统把相似的未知帖子聚在一起，并提出候选标签。
  5. 你批量决定：新增标签、并入旧标签、改成旧标签别名，或保持未分类。
  6. 词表发布新版本，只重新检查可能受影响的帖子。
关键点：100–200 条样本只负责生成“第一版常用词汇”，并不声称覆盖你未来的全部兴趣。

标签自身也需要身份和历史

- id: aesthetic.sound_walk
  name: 声音散步
  dimension: aesthetics.form
  definition: 以步行过程中的环境声音和听觉注意为主体的内容
  aliases: [听觉漫游]
  examples: [note_0182, note_2077]
  status: active
  introduced_in: 1.3
  reviewed_by: user

稳定的 id 与可变化的显示名称分开后，你可以改名、增加别名或合并标签，而不必破坏旧帖子。每张分类卡记录 taxonomy_version，以后也能知道它依据哪一版词表生成。

什么时候需要重新分类旧帖子

通常不需要重跑全部 2000 条。新增“声音散步”时，只需查找与它相似、曾经低置信度、或被标成“城市漫游/环境声音”的相关帖子。受影响集合重新分类，其余保持不动。

本轮设计问题

新帖子无法可靠匹配旧词表时，是立即打断同步要求你决定，还是先进入“待分类收件箱”，等积累一批后再集中审核？推荐后者。
